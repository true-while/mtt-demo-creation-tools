Running this prompt in Scout installs the three Demo Builder skills for your personal use.

Download and install this release for my personal use in Scout:
https://github.com/rob-foulkrod/mtt-demo-creation-tools/releases/latest/download/scout-skills.zip

Follow the bundled INSTALL.md. Install all three skill folders at the ZIP root into your configured personal skills location:
- demo-builder
- demo-builder-generate-data, including companies.csv and names.csv
- demo-builder-style-guidelines

Ask before replacing existing skills or local edits. Preserve all support files and do not fetch replacements from main. When finished, report the release used, installed skill names, versions, and actual locations. Do not claim success after merely downloading or extracting the ZIP. If installation is blocked, explain the limitation and the supported manual steps.

2. Investigate

Choose any questions that interest you. You do not need to use every prompt. Run each selected prompt separately and ask the installed skills to cite their own instructions.

Meet the skills

Using the installed instructions, explain what demo-builder, demo-builder-generate-data, and demo-builder-style-guidelines each own. Give one example of when to use each skill and one example of when not to use it. Cite the relevant rules.

Installation and destination

What is the difference between where these skills are installed and where Demo Builder places a finished package? Report only host-provided locations and destinations supported by the installed instructions. Do not guess paths.

Package structure

Based on the installed demo-builder instructions, show every package structure it can create in this host. Explain what choice selects each structure and where each result is intended to go.

Approved person names

What is names.csv for? Explain which skill validates and reads it, why another skill should not inspect it directly, and what happens when it is missing or unusable. Cite the installed data-skill rules.

Companies and domains

What does companies.csv control? Explain how approved company names and email domains are selected, and why the skills cannot invent or modify a company name. Cite the installed data-skill rules.

Consistent artifacts

How does demo-builder-style-guidelines influence Word and Excel files in the same demo package? Describe the decisions it keeps consistent and cite the installed guidance.

Things to listen for

  • The skills use Scout's configured personal skills location; the exact path must come from the host.
  • Demo Builder first asks, Will you be uploading to GitHub?
  • Yes produces a public GitHub-ready repository package; No produces a Cowork-compatible folder package in a selected destination.
  • names.csv is the approved source for fictitious person names and is validated by the data skill.
  • Skill installation location and generated package destination are different concepts.
