Install and start building

Trainers can use either Cowork or Scout. Choose the product you prefer; you do not need both. Each ZIP includes the demo builder, approved data lists, and shared style guidance for personal use.

Cowork

Download Cowork plugin in your browser. Keep the ZIP intact; do not use the Scout ZIP or GitHub's source-code archive.

  1. Open Cowork > Customize > Plugins > Add plugin.
  2. In Add a plugin, select choose a file and select the downloaded ZIP, or drag and drop the ZIP into the dialog. Follow the on-screen installation and consent steps.
  3. Confirm Demo Builder appears in the installed plugins list.
  4. Start a new Cowork conversation and paste the verification prompt below.

Tenant policy must permit installation. See advanced personal installation for personal sideloading and policy requirements. Attaching the ZIP to chat is not proof of installation.

Verify my installed demo tools without downloading, installing, deleting, or replacing anything.
Check discovery of demo-builder, demo-builder-generate-data, and demo-builder-style-guidelines.
Read companies.csv and names.csv through the installed demo-builder-generate-data skill, and open the installed
demo builder's PRESENTER-GUIDE.md, QUALITY-STANDARDS.md, and TECHNOLOGY-GUIDANCE.md references.
Check that the shared style guidance is readable. Report the skill versions and host-provided
locations where available. Mark anything you cannot inspect as unverified; do not invent paths
or infer plugin registration from files attached to this conversation.
  • Demo builder and three companion references
  • Demo-builder-generate-data skill and both approved CSVs
  • Shared style-guidelines skill

Keep existing skills until the replacement ZIP is available and validated. Confirm any required removal and recovery plan before proceeding. Full installation guide

Scout

Download Scout skills as a complete set of personal skill folders.

Download and install this release for my personal use in Scout:
https://github.com/rob-foulkrod/mtt-demo-creation-tools/releases/latest/download/scout-demo-builder.zip

Follow the bundled INSTALL.md. Install all three skill folders at the ZIP root into your configured personal skills location:
- demo-builder
- demo-builder-generate-data, including companies.csv and names.csv
- demo-builder-style-guidelines

Ask before replacing existing skills or local edits. Preserve all support files and do not fetch replacements from main. This is a Scout skills package, not a Cowork app registration.

Report the release used, installed skill names, versions, and actual locations. Verify both CSVs and style guidance are readable. Verify discovery in a new conversation if possible; otherwise mark it unverified. Do not claim success after merely downloading or extracting the ZIP. If installation is blocked, explain the limitation and the supported manual steps.
  • Demo-builder skill
  • Demo-builder-generate-data skill and both approved CSVs
  • Shared style-guidelines skill

If URL installation is unavailable, attach the downloaded ZIP and use the same prompt.

Bakery sales analysis

Paste this prompt into the demo-builder skill to generate the demonstration assets.

This demo will be based on the customization and curation of the MS-4018 course, specifically Module 6, “Excel: Uncover New Data Insights with AI.”

The customer for whom the session will be delivered operates in the food industry, specifically in the bakery sector. The demonstration should be based on the task of an administrative employee who needs to analyze sales data from a spreadsheet containing multiple products, categories, quantities produced, quantities sold, unit prices, costs, and profit margins from the past six months.

Sample bakery sales data is available at: /retail-demo-data/bakery_sales.csv
Download and open this CSV file in Excel to access 100 sample bakery products with sales performance data, cost analysis, and seasonal trends.

Using Copilot in Excel, the employee should generate sales performance analyses, identify top-performing products, calculate profitability insights, and create visual charts.

Create a Word document containing the step-by-step demonstration instructions and reference the Excel sample data for live analysis during the presentation.
